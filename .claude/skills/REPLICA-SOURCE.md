# replica-skill — installed project-local

Source: https://github.com/Jakeschincariol/replica-skill (MIT, © 2026 Jake Schincariol)
Files copied unchanged from the `main` branch's eleven `replica-*` folders.

Reviewed before installing: no network calls, no subprocess or shell execution, no reading of
credentials or the environment in any of the Python tools (standard library only); no
injection-style instructions in any SKILL.md; the only non-printing character is one U+200D in
`replica-launch/listing.py`, used to count joined emoji.

These are method files for Claude. They run only when someone invokes them by name
(`/replica-recon`, `/replica-diff`, ...).

Its own rule applies here: it rebuilds what an app *does* and how people move through it, never
what the app *owns* — not its code, logo, name, trademarks, copy or content. See the README's
"Fine print" in the source repository.
