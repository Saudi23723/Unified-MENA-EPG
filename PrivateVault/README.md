# خزنتي — Private Vault

تطبيق أندرويد بسيط وخاص لحفظ وترتيب الفيديوهات والمستندات والصور، ولا يفتحها أحد غيرك.

## المميزات
- **قفل برمز سري** (4–8 أرقام) مع إمكانية **الفتح بالبصمة**. يُقفل التطبيق تلقائياً عند الخروج منه، وبعد 5 محاولات خاطئة ينتظر 30 ثانية.
- **مخفي تماماً**: الملفات تُحفظ داخل مساحة التطبيق الخاصة، فلا تظهر في المعرض أو مدير الملفات أو أي تطبيق آخر. لا لقطات شاشة، والتطبيق يظهر فارغاً في قائمة التطبيقات الأخيرة، ولا نسخ احتياطي سحابي.
- **ترتيب بالمجلدات**: مجلدات داخل مجلدات، نقل، إعادة تسمية، حذف.
- **فلترة وبحث وترتيب**: الكل / فيديو / مستندات / صور، بحث بالاسم، ترتيب بالأحدث أو الأقدم أو الاسم أو الحجم.
- **عارض داخلي**:
  - مشغل فيديو وصوت (يكمل من حيث توقفت).
  - عارض PDF بالتكبير، ويتذكر آخر صفحة.
  - عارض صور بالتكبير والتنقل بالسحب.
  - عارض ملفات نصية.
  - باقي الأنواع (Word، Excel…) تُفتح بتطبيق آخر عند الطلب.
- **إضافة سهلة**: من زر + أو بالمشاركة (Share) من المعرض أو أي تطبيق إلى «خزنتي». خيار «نقل» يحذف الأصل من الهاتف ليبقى في الخزنة فقط.
- **حفظ نسخة خارج الخزنة** لأي ملف عند الحاجة.

## التحميل والتثبيت
كل تعديل على مجلد `PrivateVault/` يبني التطبيق تلقائياً عبر GitHub Actions وينشره في
**Releases** باسم `private-vault-<رقم>`:
1. افتح صفحة Releases في المستودع من الهاتف وحمّل `PrivateVault.apk`.
2. اسمح بالتثبيت من مصادر غير معروفة عند الطلب، ثم ثبّت.
3. أول مرة: اختر رمزك السري.

> ⚠️ ملفاتك محفوظة داخل التطبيق نفسه: **إلغاء تثبيت التطبيق يحذفها**. قبل تغيير الهاتف أو إلغاء التثبيت استخدم «حفظ نسخة خارج الخزنة» للملفات المهمة.

## مفتاح التوقيع (حتى تُثبَّت التحديثات فوق القديمة)
التحديث يُثبَّت فوق النسخة القديمة ويحافظ على الملفات فقط إذا كان موقّعاً بنفس المفتاح.
لمفتاح ثابت دائماً أضف في المستودع (Settings → Secrets and variables → Actions):
- `VAULT_KEYSTORE_BASE64`: ملف `.jks` بصيغة base64
  (`keytool -genkeypair -keystore vault.jks -alias vault -keyalg RSA -validity 36500` ثم `base64 -w0 vault.jks`)
- `VAULT_KEYSTORE_PASSWORD`: كلمة سر الملف

بدونهما يصنع أول بناء مفتاحاً ويحفظه في ذاكرة GitHub المؤقتة لباقي البناءات (يعمل، لكن GitHub قد يحذفه إذا لم يُبنَ التطبيق لأكثر من 7 أيام، وعندها يلزم حذف التطبيق وتثبيته من جديد).

## البناء يدوياً
Android Studio أو سطر الأوامر (JDK 17 + Android SDK):
```
cd PrivateVault
./gradlew assembleRelease
```
الملف الناتج: `app/build/outputs/apk/release/app-release.apk`
